## Post Text

I built an interactive Redis Workshop from scratch — a full-stack web application where you can learn Redis by doing, not just reading.

Instead of going through documentation, you get hands-on modules that let you execute real Redis commands through a clean UI and see exactly what happens under the hood.

What it covers:
- Core data structures (Strings, Lists, Sets, Hashes, Sorted Sets)
- TTL & key expiration lifecycle
- Cache-aside pattern with live hit/miss stats
- Pub/Sub messaging with real-time WebSocket delivery
- Transactions (MULTI/EXEC + WATCH for optimistic locking)
- Rate limiting with sliding window algorithm
- Distributed locks
- Session management
- Key design best practices

Tech stack:
- Backend: Java 21, Spring Boot 3, Spring Data Redis, WebSocket (STOMP)
- Frontend: React 19, Vite, Axios, SockJS
- Infra: Redis 7.4, Docker, RedisInsight

Every module includes theory sections explaining the concepts, interactive exercises to try them live, and a command log showing the exact Redis commands being executed.

The project is open source — feel free to use it for learning or teaching:
https://github.com/eilman/Redis-Workshop
